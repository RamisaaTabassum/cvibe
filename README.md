## Key Features

- **ATS Compatibility Score:** Built-in ATS (Applicant Tracking System) analyzer to score resume readability, keywords, and layout formatting.
- **AI Content Optimization (Gemini AI):** Smart AI assistance to rewrite summaries, suggest skills, and improve bullet points.
- **Structured Form Input:** Step-by-step input fields for work experience, education, projects, and certifications.
- **Live Dynamic Preview:** Real-time side-by-side preview as you edit your resume.
- **One-Click PDF Export:** Export clean, perfectly structured ATS-friendly PDF files.
- **Responsive Design:** Seamless experience across desktop, tablet, and mobile browsers.

---

## Tech Stack

- **Frontend:** React.js, Tailwind CSS
- **Backend:** Node.js, Express.js
- **AI & Analytics:** Google Gemini API / ATS Scoring Algorithm
- **Database:** MongoDB
- **Testing:** Cypress
- **Deployment:** Vercel
